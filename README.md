# Hindustan Daily — News Website UI Template

A multi-page responsive editorial news UI using plain HTML, CSS and JavaScript. This is a fictional demo brand and does not reproduce Hindustan Times branding.

## Pages
- `index.html` — homepage with lead stories, horizontal latest-news rows, section cards and newsletter UI
- `article.html` — full news post/article template with byline, hero image, article body, tags and related stories
- `category.html` — category/section page with horizontal news rows, sorting UI and load-more interaction

## Run
Open `index.html` in a browser, or use VS Code Live Server. No build step or package installation required.

## Customize
- Styling: `css/style.css`
- Interactions and sample story data: `js/main.js`
- Replace demo headlines, dates, images and placeholder article text with your own verified content.
- Images are loaded from Unsplash URLs, so internet access is needed for the demo images.

## Note
The subscription and newsletter controls are front-end demonstrations only. Connect your own backend or service before collecting real subscriptions.
